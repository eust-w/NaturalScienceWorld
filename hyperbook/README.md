# Hyperbook

This directory is the prose-first track of NaturalScienceWorld.

It is designed for chapters, diagrams, image assets, demo links, references, and long-form
theoretical synthesis.

## Structure

- `chapters/` - main Markdown chapters.
- `assets/` - images, diagrams, generated visual assets, and source files.
- `demos/` - notes that connect prose to runnable demos.
- `references/` - bibliographies, source notes, reading lists, and citation exports.

## Writing Contract

Each chapter should mark claims with one of these statuses:

- **Established**
- **Active research**
- **Working model**
- **Speculative**

Do not let new theory notes look like settled physics unless the chapter also explains the
evidence boundary.
