# New Hypotheses

This chapter is reserved for project-local theory discovery.

New hypotheses are welcome, but each one must be framed with constraints:

1. What existing theory does it preserve?
2. What problem does it try to explain?
3. What dimension or scale does it add, remove, or reinterpret?
4. What observable, mathematical, or computational consequence follows?
5. What would make it wrong?
