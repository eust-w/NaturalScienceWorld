# Preface: A Hyperbook About the Universe

NaturalScienceWorld is a working hyperbook for studying the universe across dimensions,
scales, and theoretical lenses.

It is not only a book. It is also a laboratory:

- prose explains the conceptual frame;
- code turns selected ideas into demonstrations;
- images and diagrams make abstract structure inspectable;
- structured data keeps theories comparable;
- research logs preserve the path from existing theory to new hypotheses.

## Scope

The first version covers:

- spacetime and gravity;
- quantum theory and fields;
- thermodynamics and information;
- cosmology and large-scale structure;
- complexity, life, observers, and measurement;
- speculative bridges between known theories.

## Status Discipline

The project deliberately separates four layers:

- **Established**: supported by strong evidence and standard formalism.
- **Active research**: scientifically serious but unresolved.
- **Working model**: useful inside this project as a conceptual or computational model.
- **Speculative**: an unverified hypothesis or synthesis that needs constraints, demos,
  or falsifiable consequences.
