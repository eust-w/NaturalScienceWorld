## YouTube

**Title**

NaturalScienceWorld — An Interactive Science Hyperbook (Alpha Demo)

**Description**

Explore a science hyperbook that connects a theory map, chapter previews, a research registry, and a parameter-driven toy visualization.

This is an early Alpha demonstration of the actual interface. Scientific status labels distinguish established theories, active research, project working models, and speculation. The dimension visualization is not a physics solver and does not validate a new theory. Representative citations link to the registry with source roles and scope notes. Chapters, reference coverage, and shared display metadata are still being developed; this is not a complete evidence review.

Source and local setup: https://github.com/eust-w/NaturalScienceWorld

Contributions are welcome: review a claim, add a reliable primary source, improve accessibility, or build a small reproducible teaching demo.
