# Alpha launch · v0.1.0-alpha.1

NaturalScienceWorld's first release presents a bilingual interactive hyperbook: a theory map, a toy dimension visualization, chapter previews, and a research registry. The intended audience is curious learners, educators, and contributors who want to make scientific explanations inspectable.

## Scope of this release

- Three source tracks: Markdown prose, a React/TypeScript lab, and structured research records.
- Ten entries in the JSON registry and nine theory cards in the web interface.
- Chinese and English interface copy, with desktop and mobile layouts.
- Explicit scientific status labels, representative references with source roles and scope notes, and a deterministic command-line coverage example.

This is an Alpha prototype. The dimension visualization is not a physical solver. Demo hooks name future work. The chapter reader contains previews. Citations are mapped from the JSON registry while bilingual display metadata remains separate. Eight registry entries have source links, of which seven appear in the UI; the two project-local entries have none. This is not a full evidence review. Project-local hypotheses have no confirming experimental evidence.
